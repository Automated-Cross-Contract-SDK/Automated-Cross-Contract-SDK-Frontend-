# @soroban-resurrect/adapter-xbull

Xbull wallet adapter for [Soroban-Resurrect](https://github.com/Automated-Cross-Contract-SDK/Automated-Cross-Contract-SDK-Frontend-).

```bash
npm install @soroban-resurrect/adapter-xbull @soroban-resurrect/sdk
```

See the [documentation](https://github.com/Automated-Cross-Contract-SDK/Automated-Cross-Contract-SDK-Frontend-#readme) for usage.
